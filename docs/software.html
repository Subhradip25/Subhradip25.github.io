About the Package

imdR is an R package that provides a complete pipeline for working with India Meteorological Department (IMD) gridded daily meteorological data — from raw binary download to climate index computation, trend analysis, and publication-quality maps, all within R.

Unlike existing tools, imdR bundles Survey of India (SOI) approved administrative boundaries for all 36 states and 808 districts, allowing users to extract and visualize climate data at any administrative level with a single line of code — with no additional downloads required.

The package was developed out of the practical need to streamline IMD data workflows for agricultural and climate research in India, where accessing and processing gridded climate data has traditionally required significant programming expertise.

Quick Start
Download and visualize IMD data in minutes
library(imdR) file_dir <- "~/imdR_data" # Download 2020 rainfall data rain2020 <- get_data("rain", 2020, 2020, file_dir) # Plot full India map with SOI boundaries plot_imd(rain2020, "2020-06-28", "rain") # Zoom to any state plot_imd(rain2020, "2020-06-28", "rain", level = "state", name = "Kerala") # Extract daily time series at a point goa_ts <- get_point(lat = 15.5, lon = 73.8, variable = "rain", start_yr = 2020, end_yr = 2020, file_dir = file_dir) # Plot time series with 30-day rolling mean plot_timeseries(goa_ts, variable = "rain", title = "Goa Daily Rainfall 2020") # Compute rainfall climate indices goa_idx <- compute_rainfall_indices(rain2020, level = "state", name = "Goa", file_dir = file_dir)

About the Package

statdecideR is a lightweight R package that automates the entire statistical decision workflow for one-way and two-way experimental designs. Instead of manually checking assumptions and selecting tests, you call a single function and the package handles everything: normality testing, test selection, post-hoc analysis, and publication-ready visualisation.

The package automatically runs a Shapiro-Wilk normality test on your data. If the data are normal, it proceeds with ANOVA and Tukey HSD post-hoc analysis. If not, it switches to Kruskal-Wallis with a non-parametric post-hoc test. In both cases, results are annotated with Compact Letter Displays (CLD) directly on publication-ready boxplots, faceted plots, and heatmaps.

Designed for agricultural scientists, ecologists, and researchers who need rigorous, reproducible statistical summaries without spending time on test selection or plot formatting.

Automated Workflow
1
Normality Check
Shapiro-Wilk test applied to the dependent variable. p > 0.05 indicates normality.
→
2
Test Selection
Normal data: ANOVA. Non-normal data: Kruskal-Wallis. Selected automatically.
→
3
Post-hoc Analysis
Tukey HSD (parametric) or Kruskal post-hoc (non-parametric) with CLD grouping letters.
→
4
Visualisation
Boxplots with CLD labels, faceted plots, and heatmaps generated automatically.
Installation
Install from CRAN (stable)
install.packages("statdecideR")
Quick Start
One-way analysis with automatic test selection
library(statdecideR) # Use the built-in example dataset (honeybee pollen collection) # One grouping variable: Month results <- run_statdecide( data = df_nonparam, dep_var = "Pollen", group_vars = "Month" ) # Access individual outputs results$normality_test # Shapiro-Wilk result and decision results$main_effects # Test result, post-hoc, and CLD table results$plots # Named list of ggplot2 boxplot objects
Two-way analysis with interaction, faceted plot, and heatmap
results2 <- run_statdecide( data = df_nonparam, dep_var = "Pollen", group_vars = c("Month", "Time"), # two grouping variables verbose = FALSE # suppress console messages ) # For two-way designs, additional outputs are available results2$interaction # interaction effect test and CLD results2$facet_plot # faceted boxplot across the two factors results2$heatmap # mean value heatmap (factor 1 × factor 2)
